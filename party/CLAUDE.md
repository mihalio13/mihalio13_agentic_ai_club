# Правила для ШІ-асистента в проєкті «Тусовка»

Це продакшн-сервіс для справжніх користувачів, а не демо. Перед будь-якою зміною діяти за правилами нижче.

## Команди

- Тести: `uv run pytest` (мають бути зелені, покриття ≥ 90 %)
- Перевірки: `uv run ruff check . && uv run ruff format --check . && uv run mypy . && uv run bandit -q -c pyproject.toml -r .`
- Після зміни моделей: `uv run python manage.py makemigrations`
- Після зміни залежностей: `uv export --frozen --no-dev --no-emit-project --format requirements-txt -o requirements.txt`

## Безпека: обов'язково

1. **Кожен ендпоінт, що працює з подією, бере її через `events/access.py`**
   (`get_viewable_event_or_404` / `get_owned_event_or_404`). Не писати `Event.objects.get(pk=...)` у в'юхах.
   Це стосується і «допоміжних» ендпоінтів: обкладинки, коментарів, запису, видалення коментаря.
2. Немає доступу → **404**, не 403 (не розкривати існування приватних подій).
3. Форми — лише з явним `fields = (...)`. Ніколи `fields = "__all__"`, і ніколи не брати `author`, `is_staff`, `invite_token` з запиту.
4. Будь-яка зміна стану — лише `POST` + CSRF (`@require_POST`). GET нічого не змінює.
5. Ніколи `|safe`, `mark_safe`, `format_html` з даними користувача. Ніяких inline `<script>`, `style=` чи `onclick=`: CSP їх заблокує.
6. Завантажені файли — лише через `events/images.process_cover` (перевірка вмісту, перекодування, без EXIF).
7. Редиректи на `next` — лише через `url_has_allowed_host_and_scheme`.
8. Не показувати email інших користувачів: лише `display_name`.
9. Нові дії, які можна спамити, — з `@rate_limit(...)`.
10. Секрети тільки зі змінних середовища, ніяких значень у коді.

## Надійність: обов'язково

1. Операції «перевірив → записав» (місця, кількість місць при редагуванні) — у `transaction.atomic()` з блокуванням рядка (`events/services.py`). Інваріанти дублюються constraint-ами в БД.
2. Будь-яке поле з форми валідувати на межах: порожнє, лише пробіли, завелике, від'ємне, дата в минулому, абсурдно далеке майбутнє.
3. Пагінація для всіх списків. Ніякого N+1: `select_related` / `annotate`.
4. Час зберігати в UTC (`USE_TZ=True`), показувати за Києвом.

## Тести: обов'язково

Для кожної нової фічі — тест не лише на щасливий шлях, а й на те, що **другий користувач не може** зробити те, чого не дозволяє інтерфейс (чужий id в URL, прямий POST, підмінені поля форми, анонімний доступ, повторне натискання).
